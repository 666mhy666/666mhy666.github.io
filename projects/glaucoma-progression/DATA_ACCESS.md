# Data access

The course-supplied retinal measurement file is not redistributed. Use an authorized local copy. Public artifacts contain model summaries and aggregate trajectories, not the source visit table.

## Input contract

id, time (years), GCC, base_age; each id/time pair must be unique.

Keep inputs in a local `data/` directory. Input data and model files are excluded from the public release. Course access is not assumed to confer redistribution permission.
